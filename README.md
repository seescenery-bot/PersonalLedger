# 简账 · PersonalLedger

完全离线、单机自用的 Android 个人记账 App。核心特色是**自动捕获微信支付与支付宝的收支流水**——不用手动记账。

---

## ⚠️ 兼容性声明（重要）

本项目**仅在以下设备上开发与验证**：

| 项目 | 值 |
|---|---|
| 机型 | 小米 14 **标准版**（`23127PN0CC` / `houji`） |
| 系统 | 澎湃 OS 3.0（`OS3.0.303.0.WNCCNXM`） |
| Android | 16 / API 36 |
| 分辨率 | 1200×2670 @480dpi |

**未适配小米 14 标准版以外的任何机型。** 不做多机型／多分辨率／折叠屏／平板／横屏适配，不保证在其它设备上可用。`minSdk 34` 只是构建门槛，不代表已验证。

自动捕获强依赖微信、支付宝的**界面与通知结构**，这两家任意一次改版都可能让解析失效——本项目没有服务端，无法远程修复。

---

## 功能

- **通道 A｜通知监听**：`NotificationListenerService` 读取微信支付 / 支付宝的收支通知
- **通道 B｜无障碍读屏**：`AccessibilityService` 读取「支付成功」页面，补全通知里缺失的商户名与交易单号
- **双通道互补合并**：通知给金额、页面给商户，同一笔自动合成一条完整记录
- **去重**：精确单号 + `(渠道, 方向, 金额, ±90s, 对方)` 模糊窗口
- **账单导入**：微信 `xlsx` / 支付宝 `csv`，导入前自动对账（笔数 + 金额双校验）
- **自动分类**：内置关键词规则 + 支付宝 `交易分类` 映射
- **待确认队列**：置信度不足的先挂起，由人裁决一次
- **月度统计**：分类占比、每日趋势、渠道分布、高频商户
- **记账通知**：自动记账后推送提醒，可在通知栏直接「确认 / 忽略」
- **权限健康卡片**：实时显示通知使用权 / 无障碍 / 通知权限 / 后台保活状态

## 隐私

- **不申请 `INTERNET` 权限**——App 在技术上无法联网，数据不可能离开设备
- 无任何第三方 SDK、无统计、无广告
- 账本存于本机 Room 数据库，`allowBackup=false`，云备份与换机迁移均显式关闭
- 仅声明判断两个应用是否安装的 `<queries>`，不使用 `QUERY_ALL_PACKAGES`

## 首次使用

自动记账必须开两个系统权限，**缺一个就是完全静默的**：

1. 设置 → 通知使用权 → 勾选「简账 · 微信支付宝自动记账」
2. 设置 → 无障碍 → 开启「简账 · 支付成功页补全」
3. 设置 → 省电与电池 → 应用智能省电 → 「无限制」（澎湃 OS 保活必需）

> 每次重装 APK 后无障碍服务会被系统关掉，需要重新打开一次。

## 技术要点

| 主题 | 做法 |
|---|---|
| 金额 | 全程 `Long` **分**，不碰浮点 |
| 解析顺序 | **语义判定必须先于金额抽取**，否则「零钱余额 ¥1,234.56」会被当成交易金额 |
| 去重 | 精确 `(channel, externalNo)` 优先；模糊窗口兜底；账单（CSV）为权威数据 |
| 中性交易 | 微信「收/支 = `/`」、支付宝「不计收支」→ 不入账，只参与对账 |
| 保活 | 只靠两个系统绑定服务，**零 wakelock、零后台定时、零自启**；不滥用前台服务 |
| 通知图标 | 24dp 纯白透明 vector（系统会按 alpha 单色 tint） |

更多设计决策与踩坑记录见源码注释。

## 测试

```bash
./gradlew :app:testDebugUnitTest    # 105 个单元测试
./gradlew :app:lintDebug            # lint 0 error
```

`app/src/test/resources/` 下的全部测试夹具（微信 xlsx、支付宝 csv、无障碍页面、通知样本）都是**合成数据**：商户、单号、金额、页面文本全部虚构，但完整保留了真实导出文件的格式特征（GB18030 编码、订单号尾部 Tab、Excel 序列号时间、`不计收支` 子串陷阱、¥0.00 记录等），因此解析器回归测试的语义不变。

## 已知局限

- 只在小米 14 标准版 + 澎湃 OS 3 上验证
- 微信支付通知只带 title + text，没有商户名，必须靠无障碍补全
- 无障碍读不到页面时（例如用户没开该服务）只能拿到通知里的信息
- 备份与恢复尚未实现
